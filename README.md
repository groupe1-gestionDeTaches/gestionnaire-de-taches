# Ma Liste de Tâches (Todo App)

Mini-projet Vue.js 3 + Vite — Licence 2 Génie Logiciel

## Fonctionnalités

- [ ] Ajouter une tâche
- [ ] Modifier une tâche
- [ ] Supprimer une tâche
- [ ] Marquer comme terminée
- [ ] Filtrer par statut

## Installation

```bash
npm install
npm run dev
```
